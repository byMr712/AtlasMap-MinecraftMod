# CurseForge gallery

Upload these files in the **Gallery** tab of the CurseForge project page
(**Project → Gallery → Add Image**) in the order below. Each image has a title
and a short description that can be pasted into the upload form.

| # | File | Title | Description |
| :---: | :--- | :--- | :--- |
| 1 | `01_world_map.png` | World map | The full-screen map draws itself as you explore. Pan with LMB, zoom with the mouse wheel, switch dimensions on the map. |
| 2 | `02_map_markers.png` | Markers & list | Marker list with search, distances and visibility toggles, plus the selected marker card. |
| 3 | `03_minimap.png` | Minimap | Configurable size, zoom, corner and coordinates — or hide it completely. |
| 4 | `04_marker_editor.png` | Marker editor | Name, icon, colour, coordinates, description and screenshots for every marker. |
| 5 | `05_icon_picker.png` | 183 marker icons | Items, blocks, mobs, biomes, arrows and symbols with smart RU/EN search. |
| 6 | `06_drawing.png` | Drawing & ruler | Pen, line, rectangle, circle and eraser with 60 colours, plus a two-point ruler. |
| 7 | `07_settings.png` | Settings | Eight UI designs and all minimap/marker options in one place. |
| 8 | `08_themes.jpg` | 8 UI designs | Papyrus, Stone, Deepslate, Modern Light, Modern Dark, Oak, Nether and End. |
| 9 | `09_atlas.png` | Map Atlas | Every server and singleplayer world gets its own atlas and marker collection. |
